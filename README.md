# 🎮 Game Analytics

Projeto de análise de dados de jogos desenvolvido para explorar um fluxo completo de coleta, processamento, armazenamento, análise e visualização de dados.

A ideia do projeto é simular um ambiente de análise de métricas de jogos, utilizando diferentes tecnologias em cada etapa do processo.

---

## 📊 Sobre o projeto

O **Game Analytics** reúne ferramentas de diferentes tecnologias para trabalhar com dados relacionados a jogos.

O projeto foi estruturado para representar um pequeno pipeline de dados:

```text
Geração de dados
      ↓
C#
      ↓
Dados
      ↓
SQL
      ↓
Python
      ↓
Análise
      ↓
Charts / Dashboard
      ↓
Visualização
```

Essa estrutura permite praticar conceitos que aparecem em projetos reais de análise de dados e desenvolvimento de sistemas.

## 📁 Estrutura do projeto

```text
game-analytics/
│
├── charts/
│
├── csharp/
│   └── GameDataGenerator/
│
├── data/
│
├── python/
│
├── sql/
│
├── game-analytics-dashboard.html
│
└── README.md
```

### `csharp/GameDataGenerator`

Responsável pela geração dos dados utilizados no projeto.

A utilização de C# permite simular a criação de dados provenientes de um sistema de jogos.

### `data`

Armazena os dados utilizados nas etapas posteriores do projeto.

### `sql`

Contém consultas e estruturas relacionadas ao tratamento e consulta dos dados utilizando SQL.

### `python`

Responsável pelas etapas de processamento e análise dos dados.

Python é utilizado para transformar os dados brutos em informações que podem ser analisadas.

### `charts`

Reúne os recursos relacionados à visualização dos dados e gráficos.

### `game-analytics-dashboard.html`

Dashboard responsável por apresentar visualmente os resultados da análise.

## 🔄 Pipeline de dados

O projeto segue uma abordagem semelhante a um pipeline simplificado de dados.

### 1. Geração

Os dados são produzidos utilizando o projeto desenvolvido em C#.

### 2. Armazenamento

Os dados gerados são organizados dentro do projeto para serem utilizados pelas etapas seguintes.

### 3. Consulta

SQL é utilizado para trabalhar com os dados e realizar consultas.

### 4. Análise

Python é utilizado para processar e analisar os dados.

### 5. Visualização

Os resultados são transformados em gráficos e apresentados através do dashboard.

---

## 📈 Dashboard

O projeto possui um dashboard desenvolvido em HTML para apresentar os resultados da análise de forma visual.

Arquivo:


A proposta é transformar dados brutos em informações mais fáceis de interpretar através de indicadores e visualizações.
